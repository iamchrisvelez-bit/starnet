# YouTube packaging audit

- Open the 320-pixel previews. If a word does not read, fail that file.
- Words match `words_on_thumbnail` for that video, not a punchier line the maker preferred.
- The subject matches `video_topic`. A thumbnail about a table saw is not a thumbnail of a generic workshop smile.
- The batch shares one type system. A single outlier fails.
- Face policy is obeyed. Generated celebrity likeness fails.
- Banner type sits in the center safe area described in the pipeline.
- Avatar reads as a shape at a glance. Paragraphs on an avatar fail.
- Checker counts match the tier. Preview files inside `delivery/` fail because they change the count.

The thumbnail does not need to be loud. It needs to be the video.
