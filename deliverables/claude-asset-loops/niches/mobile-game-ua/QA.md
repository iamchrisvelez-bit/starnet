# Mobile game UA audit

- The game name is spelled as in the brief, on every end card and on any still the sheet marked as branded.
- The core verb is visible. A landscape with a logo is a fail for this niche.
- Hooks differ. Three videos with the same opening frame fail.
- At 2 seconds something has already happened.
- No foreign IP, no copied store listing, no star ratings, no "as seen in" marks they did not supply.
- Client-supplied mode: frames match the footage. A regenerated character that replaces their hero fails.
- Original-staging mode: the proposal said it was staged, and the picture does not reproduce a named game's interface.
- End-card words match `cta` and `on_screen_words`.
- Checker result is clean, including duration on the hooks tier.

Fun is not a requirement. The verb and the name are.
